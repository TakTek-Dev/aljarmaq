# ثيم الجرمق الاخباري

ثيم إخباري عربي (RTL) جاهز للتركيب — HTML5 + CSS3 + JavaScript عادي، بلا أي
مكتبة خارجية وبلا خطوة بناء إجبارية. افتح `index.html` وسيعمل.

## كيف تعمل الأنماط

كل صفحة تربط ملفًا واحدًا فقط:

```html
<link rel="stylesheet" href="css/style.css">
```

و`style.css` لا يحتوي أي قاعدة بنفسه — وظيفته ترتيب استدعاء باقي الملفات
بـ `@import`. الترتيب مقصود: المتغيّرات ثم العام ثم الخاص، و`responsive.css`
أخيرًا حتى تسبق قواعده ما قبلها بلا حاجة إلى `!important`.

**لا يوجد أي `style=""` داخل الصفحات** — كل التنسيقات في ملفات CSS خارجية،
وحالات `:hover` و`:focus` معرّفة بأصناف حقيقية لا بسمات خاصّة.

### تغيير الهوية

عدّل `css/variables.css` وحده. مثلًا لتبديل لون التمييز:

```css
:root { --brand-amber: #c9873f; }
```

لصور بالأبيض والأسود في كل الموقع:

```css
:root { --photo-filter: grayscale(1) contrast(1.08); }
```

### للإنتاج (اختياري)

`@import` يحمّل الملفات على دفعتين. لدمجها في ملف واحد:

```bash
npx lightningcss --bundle --minify css/style.css -o css/style.min.css
```

ثم بدّل الرابط في `<head>` إلى `css/style.min.css` — دون أي تغيير آخر.

## كيف يعمل الجافاسكربت

كل صفحة تربط الوحدات التي تحتاجها فقط، بـ `defer`، و`main.js` أخيرًا:

```html
<script src="js/navigation.js" defer></script>
<script src="js/filters.js" defer></script>
<script src="js/main.js" defer></script>
```

`defer` يعني: التحميل بالتوازي مع بناء الصفحة، والتنفيذ بالترتيب بعد اكتمالها —
فلا حاجة لوضع السكربتات في نهاية `<body>`.

كل وحدة تسجّل نفسها على `window.Aljarmaq` وتخرج بهدوء إن لم تجد عناصرها في
الصفحة، لذا لا يضرّ ربط وحدة زائدة ولا يسقط الموقع إن نقصت واحدة.

**لإضافة وحدة جديدة:** أنشئ الملف على نفس النمط، سجّلها باسمها على
`window.Aljarmaq`، وأضف الاسم إلى مصفوفة `MODULES` في `js/main.js`.

## المكوّنات المشتركة (partials)

الهيدر والفوتر والقائمة والعمود الجانبي مكتوبة **مرّة واحدة** في `partials/`.
الصفحات تحتوي نسخة مُدرَجة منها بين علامتين:

```html
<!-- #include partials/header.html -->
   …محتوى مُدرَج تلقائيًا — لا تعدّله هنا…
<!-- /include -->
```

بعد أي تعديل في `partials/` شغّل:

```bash
node tools/build-partials.js
```

للتحقّق فقط (مفيد في CI — يخرج بالرمز 1 إن كانت الصفحات قديمة):

```bash
node tools/build-partials.js --check
```

هذا الأسلوب يبقي الصفحات **HTML ثابتًا بالكامل**: تعمل بفتحها من القرص مباشرة،
وعلى أي استضافة، وداخل أي نظام إدارة محتوى — بلا `fetch` وقت التشغيل.

### تمييز الصفحة الحالية في القائمة

ملف `partials/navigation.html` نسخة واحدة لكل الصفحات. الصفحة الحالية تُحدَّد من
سمة على `<body>`:

```html
<body data-nav="local">
```

و`js/navigation.js` يضيف `.is-active` للرابط المطابق. المفاتيح المتاحة:
`home` · `local` · `opinion` · `video` · `album` · `live` · `about`.

## الخطوط

الثيم يستخدم افتراضيًا خطوط Google عبر `<link>` في `<head>`:

| الخط | الاستعمال | المتغيّر |
| --- | --- | --- |
| Almarai | متن عربي | `--font-ar` |
| Readex Pro | العناوين | `--font-head` |
| Archivo | الأرقام اللاتينية | `--font-lat` |

لاستضافتها محليًا (أسرع وأفضل للخصوصية) اتبع التعليمات في `fonts/fonts.css`.

> **ملاحظة RTL:** أي رقم أو نصّ لاتيني داخل الصفحة يأخذ الصنف `.lat` — يمنع
> انقلاب اتجاه الأرقام ويستخدم أرقامًا متساوية العرض.

## إمكانية الوصول

- **رابط تخطٍّ** أول عنصر في كل صفحة: `Tab` ثم `Enter` يقفز فوق الشريط والقائمة
  إلى `<main id="main">` مباشرة.
- **معالم HTML5** كاملة: `header` · `nav` · `main` · `aside` · `footer` — لكل صفحة
  `<main>` واحد و`<h1>` واحد.
- **الشريط العاجل** يتوقّف عند المرور بالفأرة أو التركيز بالكيبورد (WCAG 2.2.2)،
  والنسخة المكرّرة منه تحمل `aria-hidden` فلا تُقرأ العناوين مرّتين.

### الشريط العاجل و«تقليل الحركة»

الشريط يتحرّك دائمًا، حتى مع تفعيل **تقليل الحركة** في نظام الزائر — لأن الحركة
هي وسيلة عرضه الوحيدة (عرضه ثلاثة أضعاف الشاشة، وإيقافه يخفي ثلثي العناوين).
الاستثناء مكتوب صراحةً في نهاية كتلة `prefers-reduced-motion` في `css/base.css`.

البديل المتاح للمستخدم بدل الإيقاف الكامل: الشريط **يتوقّف عند المرور بالفأرة
أو التركيز بالكيبورد** — وهو ما تطلبه WCAG 2.2.2.

## نقاط الاستجابة

كلها في `css/responsive.css` بمنهج desktop-first:

| النقطة | ما يحدث |
| --- | --- |
| `1180px` | الهامش 24px، الأعمدة غير المتساوية تنهار إلى عمود |
| `980px` | التنقّل الأفقي يُخفى وتظهر القائمة الجانبية، الشبكات إلى عمودين |
| `680px` | الهامش 16px، كل شيء عمود واحد |
| `420px` | تصغيرات أخيرة للشاشات الضيقة جدًا |

يوجد كذلك قسم `@media print` يخفي عناصر التصفّح ويترك المحتوى.

## الصور

صور المحتوى في الصفحات روابط خارجية من Wikimedia Commons كعيّنات فقط.
عند التركيب استبدلها بصور الموقع الحقيقية — يفضّل وضعها في `images/`
واستخدام مسار نسبي مثل `images/news/xxx.jpg`.

شعار الموقع موجود بنسختين:

- `images/logo.png` — للخلفيات الفاتحة (الهيدر والقائمة)
- `images/logo-light.png` — للخلفيات الداكنة (التذييل)
